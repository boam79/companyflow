# 수용 기준 빠른 조회

원문: [PRD-v1.3.md](PRD-v1.3.md) 12절. 구현·테스트 시 이 표를 먼저 보고, 애매하면 PRD 전문을 연다.

| ID | 완료 기준 |
|---|---|
| AC-01 | 회사 생성 → 최초 관리자 연결 → 지정 PC 초기 설정 → 사용 시작. 코드 수정·재배포·수동 DB 변경 없음 |
| AC-02 | 두 회사의 라벨·필드·단계·화면·알림·문서·권한이 독립 |
| AC-03 | 상태 이름·결재 단계를 바꿔도 공통 확정 명령과 수량 효과 유지 |
| AC-04 | 일반 비품을 발주 항목별로 구분하고 전용 목록·통계에서 조회 |
| AC-05 | 분할수령·검수 통과분 반품·불량 거절품 반환을 구분. 순수령·잔량·재고 일관 |
| AC-06 | 검수 통과 수량 = 창고 + 자산 + 비재고 배분 |
| AC-07 | 초안은 현재고 미반영. 입출고 확정 즉시 원장·잔량 갱신 |
| AC-08 | 반출은 성명 또는 부서 하나 이상. 과거 값을 목록·통계·Excel에 보존 |
| AC-09 | 확정 실패 시 업무·원장·자산·중복방지 기록 일부만 남지 않음 |
| AC-10 | 재클릭·재시도·Relay 재수신에도 한 번만 반영 |
| AC-11 | 정정·반납·반품은 원거래 연결. 유효 수량 초과·잘못된 후속 취소 차단 |
| AC-12 | 창고 이동은 양쪽 잔량만 바꾸고 회사 전체 재고는 불변 |
| AC-13 | 직접 자산화·전환에서 수량과 자산 수 일치. 재고·자산 중복 보유 없음 |
| AC-14 | 통계 요약·상세·Excel이 같은 원본·필터·권한·날짜 포함 규칙 |
| AC-15 | 스캔본에서 후보 추출 → 원본 근거 확인 후 계약 초안 한 건 |
| AC-16 | OCR 실패·낮은 신뢰도·필수값 누락·파일 중복 처리. 원본·수정 이력 보존 |
| AC-17 | 게시 Template 불변. 진행 업무·생성 문서는 사용한 버전·입력값 보존 |
| AC-18 | 모듈 OFF에도 권한 있는 과거 조회·내보내기. 필수 연동을 조용히 생략하지 않음 |
| AC-19 | 재실행 후 로컬 보존. 다른 회사 DB·파일·화면 접근 없음 |
| AC-20 | 중앙 서버·로그에 평문 업무 원본 없음. 다른 회사 Relay 차단 |
| AC-21 | Relay는 로컬 저장 후 ACK. 재접속 시 보관기간 안 미수신 재조회. 만료는 재전송 필요 |
| AC-22 | 백업에 DB·첨부·설정·Template 포함. 잘못된 복원은 현재 원본 보존 |
| AC-23 | 직원·입사·퇴사·명찰이 Workflow·문서·자산 배정·회수와 연결 |
| AC-24 | 커밋 직후 종료·재실행에도 문서·알림 대기 작업 누락·중복 없음 |
| AC-25 | 구매 없이 직접 입고 확정. 원장·현재고·입고 통계 한 번만 증가. 구매 모듈 OFF여도 재고 권한으로 처리 |
| AC-26 | 구매 미연결 입고가 발주·수령 지표를 만들지 않음. 사후 연결에도 중복 없음 |
| AC-27 | B회사 필드·결재·문서 게시 후에도 A회사 활성 설정·화면·검증·업무·문서 유지 |
| AC-28 | 공통 기본 설정 갱신·B 되돌리기가 A와 진행 업무 버전을 바꾸지 않음. 권한 없는 게시 차단 |
| AC-29 | B에서만 신규 기능 ON이면 A에 새 화면·필수 입력·알림·효과가 없음 |
| AC-30 | B 모듈 동작 버전·데이터 변환 후에도 A 버전 연결·DB·기존 업무 유지 |
| AC-31 | 운영 관리자만 회사 생성·최초 관리자 지정. 자가 승격·타 회사 사용자 관리·미수락 초대 접근 차단 |
| AC-32 | 생성·연결·초기화 실패 후 같은 작업 재개 시 중복 없음. 검증 전 사용 가능 표시 금지 |
| AC-33 | 회사 관리자가 해당 회사에 사용자 연결. 확인 후 허용 역할만 활성화. 새 B가 A에 영향 없음 |
| AC-34 | 동시 초기화에도 원본 장치 1개. 새 PC·DB 유실은 빈 DB 대신 복원·교체 안내. 휴대폰으로 원본 등록 금지 |

운영 해석 (D-32): AC-02·19·27은 한 화면에 두 회사 원본을 섞지 않는다는 뜻이다. 운영 계정이 회사를 고른 뒤 그 파일만 여는 것은 허용한다. 상세 [`tenants.md`](tenants.md).

## 개발 검증 예시 (PRD)

일반 비품 복사용지 10 발주 → 6·4 정상 수령 → 반출 3 → 반납 1 → 회사 현재고 **8**.

2개를 다른 창고로 이동 → 원창고 6, 대상 2, 회사 합계 8. 반출 재시도·이동 재시도 후에도 수량 동일. 초안은 수량에 영향 없음.
